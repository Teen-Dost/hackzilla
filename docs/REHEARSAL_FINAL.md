# Final demo rehearsal — pacing & confidence

## Timing targets (3:00 total)

| Block | Time | Emotional beat |
| --- | --- | --- |
| Landing | 0:00–0:25 | **Scale** — ticker + stats without over-explaining |
| Feed | 0:25–0:50 | **Density** — scroll a little, one sentence on AI tags |
| Doubt → match | 0:50–1:35 | **Tension → release** — bot interest → match → confetti |
| Session | 1:35–2:10 | **Trust** — chat + timer + “real product” moment |
| Leaderboard / AI | 2:10–2:50 | **Ambition** — campus + longitudinal AI |
| Close | 2:50–3:00 | **Founder** — one crisp line on why you win |

## Transition timing

- **Pause 1 full breath** after each navigation before talking again (reduces rushed feel).
- After match navigation, **wait for session header** to paint before speaking (half second).

## Fallback narration (if X fails)

| Failure | Line |
| --- | --- |
| Feed error | “We’re hitting a cold DB in preview — one retry and we’re back; the shell is the product story.” |
| Match fails | “Interest is there in the DB; I’ll show the session history list instead — same orchestration.” |
| Clerk | “Auth is Clerk by design — here’s the signed-in rehearsal account.” |

## Emotional pacing

- Start **confident**, not defensive (“we built…”).
- Middle **curious** (“watch what happens when…”).
- End **inevitable** (“this is the wedge because…”).
